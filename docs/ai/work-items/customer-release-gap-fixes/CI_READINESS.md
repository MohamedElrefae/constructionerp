The workflow checks out the tested Frappe commit `81aadb9ba1bc07abccd8f720af80f4f2fb4a68a0` and ERPNext commit `2807c9f08fff3f161c0a2e10745a26aa6331ffd5` after Bench's supported branch-based initialization/app-fetch commands. The installed Bench source shows `bench init` and `bench get-app` clone with `--depth 1` by default, set the clone remote name to `upstream`, and install each fetched app editable immediately. The workflow therefore fetches each exact SHA explicitly with `git fetch --depth=1 upstream <sha>`, checks out `FETCH_HEAD` detached, and asserts `git rev-parse HEAD` equals the expected SHA. It re-runs `bench setup requirements frappe` after pinning Frappe and syncs both pinned framework apps before fetching Construction, so declared requirements are installed from the pinned source before continuing setup. These editable installs are not a dependency lock and do not prune every package that may have been installed by an earlier branch version. Bench's CLI exposes `bench init --frappe-branch` and `bench get-app --branch`; it has no commit-SHA option for either operation.

The disposable GitHub Actions MariaDB service now uses 10.11, matching the isolated candidate test runtime recorded in this work item's verification. This CI service change does not qualify other database versions.

These source pins improve repeatability for the tested framework revisions. They do not freeze the full runner: the Ubuntu hosted image, tagged GitHub actions, apt repository packages, the `frappe-bench` installer, Python transitive dependency resolution, and Node/npm packages can change. The workflow is therefore a reproducible source selection with recorded run evidence, not a fully locked vendor/runtime image. Vendor provenance, dependency advisory review, support matrix qualification, and independent customer-release approval remain separate open gates. In particular, a passing manually dispatched run establishes only the selected jobs on the recorded runner and candidate commit; it is not complete app, browser, capacity, security, upgrade, or release certification.
