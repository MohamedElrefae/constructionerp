## Outcome model — proposed and not qualified

A campaign binds a nonempty reviewed catalog, and each case binds at least one mandatory variant. One separately authorized attempt executes one variant in one bound disposable generation. Stop is permanent for that attempt; safe cleanup is separate. A fresh attempt needs its own current authorization; no broader-access retry. Transaction correlation and read-only proof never transfer to another attempt or session. Exact catalog, observer, authority and bindings are unqualified.

Each attempt result is PASS, FAIL, UNKNOWN or NOT_RUN. NOT_RUN means not started, including an authorized attempt that never executes. Started but interrupted or missing evidence is UNKNOWN unless an independently established contrary finding is preserved. Expected denial is PASS only when the reviewed exact oracle, independent positive controls, binding, cleanup and sealing are established; an incidental stop, blanket denial or missing witness is UNKNOWN. Open adverse findings always block completion and cannot be silently cleared by a later PASS.

For each variant retain every authorized attempt: no attempts or all NOT_RUN => NOT_RUN; any unresolved evidence, UNKNOWN, invalidation or a mixture of executed and NOT_RUN => UNKNOWN; otherwise any uncorrected independently established FAIL => FAIL; otherwise all attempts PASS => PASS. Missing evidence is not absence. A confirmed adverse finding is recorded separately even when aggregate classification is UNKNOWN. A later PASS cannot erase it; an independently adjudicated, authenticated correction with recorded rationale and no prohibited content is required, and authority/criteria are unqualified.

For a case: all required variants NOT_RUN => NOT_RUN; any UNKNOWN or a mix of NOT_RUN and executed results => UNKNOWN; otherwise any FAIL => FAIL; otherwise all PASS => PASS. Campaign has two separate reported dimensions: completeness is INCOMPLETE if catalog/case is empty or unapproved, any case UNKNOWN/NOT_RUN, any unresolved adverse finding, or required evidence, reconciliation, independent attestation, cleanup or sealing missing/uncertain; otherwise completeness is COMPLETE. Failure status is FAILED whenever any independently confirmed uncorrected attempt, case or adverse finding is FAIL, even when completeness is INCOMPLETE; otherwise it is NO_CONFIRMED_FAILURE. A confirmed FAIL must remain visible as an adverse finding and cannot be erased by missing evidence or later PASS. LAB_CASES_COMPLETE requires COMPLETE, NO_CONFIRMED_FAILURE, all cases PASS and all required independently authenticated reconciliation and attestations. This is a bounded lab classification only, never target qualification or G0 closure. Scoring cannot be applied until independent review establishes the catalog, oracle and safe evidence format.

## Version classification — candidate, not qualified

Exact ASCII bytes only; no trimming, case folding or silent normalization. First match the exact accepted full reference as a literal. For any other input, the numeric core is exactly three nonempty ASCII decimal digit sequences separated by two dots; it ends at end-of-input or immediately before a hyphen starting a suffix. A dot after the third component is an extra core segment, not a suffix. Suffix characters after that hyphen are not numeric-core components. Classify malformed, non-ASCII, control/whitespace, ambiguous syntax, numeric-core leading-zero ambiguity or oversized input as UNKNOWN before numeric comparison. Grammar and bounds must be independently reviewed before use. For a structurally valid numeric core, a numeric triple different from `10.11.14` gives NUMERIC_MISMATCH and stop. With core `10.11.14`, only exact full reference `10.11.14-MariaDB-0ubuntu0.24.04.1` can yield MATCH_REFERENCE; bare version, changed/unrecognized suffix or otherwise unexpected value gives UNKNOWN and stop. Suffix numeric components are not extra core segments; an extra numeric core segment is UNKNOWN. All non-match raw inputs, lengths and hashes are suppressed; even an outcome is suppressed if it indirectly reveals a protected value. If evidence cannot be safely recorded, INCOMPLETE. No parser, output domain or independent vectors are qualified; no current target version is claimed.
